# MQTT Device Simulator icon v2

The icon combines two simulated device terminals, bidirectional MQTT message flow, and a subtle `M` silhouette.

- `mqtt-simulator-icon-v2.png`: 1024 × 1024 transparent master asset
- `mqtt-simulator-icon-v2.ico`: Windows multi-resolution icon (16, 24, 32, 48, 64, 128, 256 px)

Palette: deep navy, cyan, turquoise, and electric blue. The mark is designed to remain recognizable in both the light and dark application themes.
